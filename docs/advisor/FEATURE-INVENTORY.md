## Point definitions and limitations

Region names resolve to SDK-returned mesh indices, never hand-authored anatomical coordinates: outline=FACE_OVAL(1), left/rightEye=LEFT_EYE(6)/RIGHT_EYE(7), left/rightBrowTop=LEFT_EYEBROW_TOP(2)/RIGHT_EYEBROW_TOP(4), brow bottoms=3/5, upperLipTop=8, upperLipBottom=9, lowerLipTop=10, lowerLipBottom=11, noseBridge=12. The bridge exports regions[name] index lists alongside all 468 points. Detection fallback uses FaceContour types with exact supported counts: outline36, eyes16 each, brows5 each, upper outer lip11, other lips9, bridge2, bottom nose3. noseBaseWidth deliberately remains Face Detection even when mesh is present. A feature using a detection fallback region records that source conservatively, including detection-based outline and eye-axis prerequisites.

Width bands are polygon descriptors at normalized vertical positions, **not** verified cheekbone/jaw anatomy. lowerFaceHeight is mouth-centroid-to-bottom distance, **not** validated facial thirds. Brow arch uses maximum perpendicular distance from its endpoint chord, not eyelid or brow-style classification. Lips use contour centroid gaps, not anatomical tissue thickness. Relative Z span and projected triangle area consume all mesh vertices/topology locally; they are not shipped to Gemini and do not estimate physical depth. Rendering uses SDK triangle indices.

Unsigned EyeTilt/BrowTilt = absolute atan2 angle of horizontal extrema in eye-aligned axes divided by pi, range 0–.25. This is a projected contour descriptor, not anatomical canthal tilt. All shared features carry exact conservative source enums in summary.featureSources; backend adds trusted formula/normalization/range/quality metadata by key. Schema v2 never sends raw coordinates.

Not extracted: anatomical upper/middle/lower thirds (no validated forehead/hairline anchors), detailed eyelid labels, ethnicity/gender, attractiveness, health/skin, undertone, physical nose height or bone projection. These are unavailable or not established by this SDK geometry. No face-shape classifier was added.

Native observation inventory: all detected boxes/Euler angles, face count, all available landmarks (type plus X/Y), eye-open/smiling nullable probabilities, all contour groups, mesh468 XYZ, returned triangle indices and named SDK region indices. Tracking ID is intentionally omitted because a single selfie does not need identity tracking. Landmarks are retained in memory for diagnostics/quality extensions; not misrepresented as local rule inputs.
