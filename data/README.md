Vietnam operating areas are bundled from https://provinces.open-api.vn/api/v1/?depth=2 (retrieved 2026-10-01).

This is the legacy province/district catalog before the July 2025 administrative changes. It is used for the requested familiar district-based service area selector, not for legal addresses. The UI labels this catalog accordingly. Province and district codes must be interpreted with this version.

Only names and codes are retained. The backend embeds the same catalog in Data/vietnamAreas.json to validate parent/child selections.
